# Apple (AAPL) Stock Market Data Analysis

## Project Overview
This project analyzes historical Apple Inc. (AAPL) stock market data from December 1980 to November 2024 using Microsoft Excel and Python.

## Tools Used
- Microsoft Excel
- Python
- Pandas

## Key Analysis
- Historical closing price trends
- Daily stock returns
- Trading volume analysis
- Summary statistics and volatility
- Data-quality checks

## Files
- `Stock_Market_Data_Analysis.xlsx` — Excel workbook with analysis and dashboard
- `AAPL_Cleaned_Data.csv` — Prepared dataset
- `inspect_data.py` — Python data inspection script

## Data Quality
An unusually large daily return was identified for 29 September 2000. This record is flagged for further verification rather than being automatically removed.
